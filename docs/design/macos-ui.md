# Mini Desk 的 macOS 界面约定

本次优化以 Apple Human Interface Guidelines 为依据，参考提醒事项与备忘录的内容优先、清晰层级和克制用色。网页采用适合浏览器的材质效果，不声称复现原生 Liquid Glass 的光学渲染。

## 表面与层级

- 四区工作台继续服务于同时查看、拖动和编辑的桌面工作流。
- 四个区域、顶栏和区域间缝隙共用同一中性底色，避免多种接近的灰白色交错。
- 分组标题与标签栏共用一种灰色；分组内容继承工作台底色。白色用于卡片与选中控件，深色模式采用相同的层级关系。
- 浮动菜单可使用半透明材质；顶栏、大段文本、编辑器和对话框保持清晰。
- 以留白、轻分隔线和字重建立层级，避免每个元素都带厚边框或强阴影。
- 记事本标签使用连续的中性底，当前标签以实色与轻阴影区分，不依赖颜色判断选中状态。

## 颜色与控件

- 蓝色表达交互和焦点，并统一 Naive UI 的主题色，避免混入默认绿色。
- 区域标题图标使用少量功能色；正文以中性色为主。
- 逾期提醒的时间保留警示色，任务正文保持正常阅读颜色；已完成、重点标记延续现有行为。
- 明暗模式分别定义表面、分隔线、文字和功能色。
- 设置提供外观的跟随系统、浅色和深色选择，复用现有持久化与系统主题监听。
- 桌面顶栏不再提供重复的主题切换按钮。仅跟随系统模式响应系统明暗变化，显式浅色或深色选择会持续保留，包括刷新后。
- 菜单以分隔线组织偏好、连接、帮助和版本入口，破坏性操作继续使用已有确认流程。

## 交互与适配

- 使用系统字体栈、现有图标库和一致的控件圆角。
- 保持已有键盘操作、拖动、独立滚动、列宽调整、折叠和编辑能力。
- 无材质支持、减少透明度和增强对比度时使用更实的表面；已有减少动态效果规则继续生效。
- 手机入口与桌面工作台保持各自布局，不把四列压缩进手机屏幕。
- 继续维护中英文文案，长标题截断、窄列适配和编辑器镜像排版的一致性。
