Features

先放下，再慢慢推进。

Mini Desk 不把桌面变成复杂系统。它只是把每天容易散掉的几样东西放近一点。

截图先收好

Ctrl+V 粘贴截图，缩略图、预览、复制和拖拽排序都在同一处，不急着打断当下。

动作少走路

常用链接、复制文本和 API 请求做成按钮，重复操作轻轻点一下就好。

提醒不催人

想法有抽屉

临时想法和推进步骤可以先写下来，和图片、动作、提醒放在同一张桌面。

设计原则
桌面会呼吸。东西多起来，它会轻轻提醒你降温。

内容少的时候，它是轻盈的；东西多起来，它会变成略满；再堆下去，它会提醒你：桌面有点热，要不要一起降温。

Privacy

东西留在你的浏览器里。

Mini Desk 默认不依赖后端。看板状态、图片原文和自定义资源都安放在当前浏览器站点内，没有账号，也没有上传。

桌面状态 保存在 localStorage 的 mini-desk-state-v1
图片原文 保存在同源 IndexedDB 的 mini-desk-images-v1
搬家备份 通过数据导入与导出完成，删除和清理前都会先确认。
Workflow

打开就是桌面，不需要再搭流程。

先把零碎材料放下，再把重复动作收短，最后只盯住今天真正要推进的几件事。

1

收好视觉证据

粘贴图片或拖入素材，把当下的视觉证据先收好。

2

收短重复动作

把常用链接、复制文本和 API 请求做成顺手的快捷动作。

3

盯住今日重点

单击新增提醒事项，星标后轻轻放进今日重点。

4

留下回来线索

在便签里写下推进步骤，给下一次回来留一条线索。
