Features

先放下，再慢慢推进。

Mini Desk 不是一个会给你派活的系统。它只是把每天容易散掉的几样东西——放近一点，收好一点。

截图先收好

Ctrl+V 一粘，截图就收进桌面。不用再翻聊天记录、不用堆满桌面——想要的那张图，一抬眼就在。

Ctrl + V

动作少走路

每天要打开十次的链接、要复制十次的文本，做成一个按钮。点一下，省下十次来回。

提醒不催人

今天真正要做的几件事，轻轻放在眼前。它会让你看见进度，但绝不会用红点催你。

想法有抽屉

脑子里冒出来的念头，随手就放进抽屉。和图、链接、待办待在同一张桌面，再也不会想了就忘。

设计原则
桌面会呼吸。东西堆多了，它会轻轻提醒你慢下来。

内容少的时候它是轻盈的，多起来会略满，再堆下去——它会提醒你：桌面有点热了，要不要一起降降温。这不是又一张待办清单，而是一张会替你看着自己的桌面。少一点，慢一点，反而做得完。

Privacy

最让人安心的：它只待在你这里。

不用上传，不用账号，也不用去相信某个云。桌面上的每一笔、每一张图，都只活在这台设备、这个浏览器里——它是你的桌面，只有你能看见。

桌面状态 保存在 localStorage 的 mini-desk-state-v1
图片原文 保存在同源 IndexedDB 的 mini-desk-images-v1
搬家备份 通过数据导入与导出完成，删除和清理前都会先确认。
Workflow

打开，就是你的桌面。

不用搭建、不用配置。打开就是一张空桌面——先把零碎放下，再把重复收短，最后只盯今天真正要推完的几件事。

1

收好视觉证据

粘贴图片或拖入素材，把当下的视觉证据先收好。

2

收短重复动作

把常用链接、复制文本和 API 请求做成顺手的快捷动作。

3

盯住今日重点

单击新增提醒事项，星标后轻轻放进今日重点。

4

留下回来线索

在便签里写下推进步骤，给下一次回来留一条线索。
