# 示例空间

三个可直接导入的演示空间（`miniDeskWorkspaceExport` 单空间导出格式），
用于体验 / 演示「导入空间」功能。

| 文件 | 主题 | 亮点 |
| --- | --- | --- |
| `人生清单.json` | 人生清单 | 3 组快捷标签（攒钱计划 / 说走就走 / 新技能）、多行文本模板按钮、2 个提醒列表、3 个便签页（清单 / 打卡进度 / 梦想基金） |
| `前端进阶学习.json` | 学习前端开发 | 课程文档与刷题链接、`app` 类型按钮（VS Code）、`api` 类型按钮（一言格言）、每日打卡 + 阶段目标双列表 |
| `我的工作台.json` | 日常工作 | 高频入口与协同工具（钉钉 / 飞书 / 企微 `app` 按钮）、日报与会议纪要模板、今日要务 + 本周跟进双列表 |

## 主题示例（`themes/`）

面向客户演示与宣传素材的四套主题空间，同样为单空间导出格式：

| 文件 | 主题 | 亮点 |
| --- | --- | --- |
| `themes/健身训练.json` | 运动健康 | 训练计划 / 饮食 / 身体数据三页便签、打卡与拉伸文本模板、周训练 + 恢复双列表 |
| `themes/旅行规划.json` | 出行计划 | 川西 7 日行程、订票订房入口、行前检查与每日游记模板、出发前 + 旅途中双列表 |
| `themes/自媒体创作.json` | 内容创作 | 选题库 / 脚本大纲 / 数据复盘、`api` 文案灵感按钮、发布文案模板、更新排期列表 |
| `themes/家庭理财.json` | 记账理财 | 固定支出 / 储蓄目标 / 月度复盘、账单日清单模板、本月账单 + 定投双列表 |

文件结构由 `src/__tests__/import-theme-samples.test.ts` 守护。

## 导入方式

1. 打开应用右侧「设置」→「导入空间」
2. 选择任意一个 JSON 文件
3. 确认「添加」即可（若与现有空间同名，可选覆盖或新增）

## 说明

- 示例中的提醒时间（`notifyAt`）覆盖 2026-08 → 2027-03，导入后即为未来时间，可直接观察提醒效果；随时间推移可自行调整。
- 文件结构由 `src/__tests__/import-samples.test.ts` 守护：导入格式若有变化，测试会提示同步更新示例。
