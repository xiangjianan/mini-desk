一天的碎事，各就各位

从导入一套主题空间开始：快捷动作、提醒事项、便签和图床，十分钟布置好自己的节奏。

01

导入主题空间，十秒上手

设置 → 导入空间，选一个 JSON 文件，看板即刻成形。同名空间可选覆盖或新增，示例空间开箱即用。

  • 单空间 JSON 导入导出
  • 同名冲突自动处理
  • 7 套官方主题示例
02

提醒事项，轻重自分

星标置顶、截止时间、今日重点自动聚合到顶部。临近和超期的事项会用底色和警示线轻轻提醒，不吵不闹。

  • 星标 + 常用整点截止
  • 完成进度一眼看清
  • 双列表自由分组
03

截图照片，先放进图床

Ctrl+V 粘贴截图，或者把照片直接从桌面拖进来。点开大图慢慢看，滚轮缩放、键盘切换，原文躺在 IndexedDB 里。

  • 粘贴 / 拖放即入
  • 原图预览与缩放
  • 大图不占 localStorage
▶

快捷动作

链接、应用、API、文本模板。一键打开钉钉飞书，一键复制日报模板。

▶

便签多页签

点进去就写，Tab 缩进、Shift+Tab 回退。一个页签一个主题。

▶

多工作空间

工作、学习、旅行各就各位，顶栏一键切换，互不打扰。

▶

浅色 / 深色

随手切换主题，参考 Apple HIG 的紧凑低干扰界面。

每个空间都可以导出为单个 JSON 文件，换台电脑导入即可继续。迁移成本约等于零。
